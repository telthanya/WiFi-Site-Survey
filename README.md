# Wi-Fi Site Survey

โปรแกรมสำรวจ Wi-Fi (site survey) ทำงานบนเดสก์ท็อป: Python ในเครื่อง + หน้าจอทำงานบนเบราว์เซอร์ที่ `127.0.0.1`
(ไม่ส่งข้อมูลออกอินเทอร์เน็ต)

## ฟีเจอร์
- อัปโหลดแปลนอาคาร (PNG/JPG) + ตั้งสเกลเป็นเมตร
- คลิกวางจุดวัด → สแกน Wi-Fi จริงจากการ์ดของเครื่อง (SSID, BSSID, RSSI, ช่อง, ย่าน 2.4/5/6 GHz) เฉลี่ยหลายรอบได้
- **วัดแบบ active** ต่อจุด: link rate (rx/tx Mbps) ของ AP ที่เชื่อมต่ออยู่ + ping หา gateway/โฮสต์ที่กำหนด (latency, jitter, packet loss) แล้วเลือกให้ heatmap แสดงเป็น RSSI / link rate / latency / jitter / loss ได้ (ต้องเชื่อมต่อ Wi-Fi อยู่ตอนวัด; ยังไม่วัด throughput จริง)
- Heatmap ความแรงสัญญาณ (ประมาณค่าระหว่างจุดแบบ IDW) กรองตาม SSID / BSSID ได้ พร้อมเปอร์เซ็นต์พื้นที่ที่ผ่านเกณฑ์
- วาง AP แล้วจำลองการครอบคลุม (log-distance path loss, ปรับ exponent/กำลังส่ง/ย่านได้) และโหมดสแกนจำลองสำหรับฝึก/ทดสอบ
- รายงาน PDF (สรุป, heatmap, ตารางจุดวัด, การใช้ช่องสัญญาณ, รายการ AP) · ส่งออก CSV / JPG / JSON
- บันทึกโปรเจกต์ใน `~/.wifi-survey/projects` (เปลี่ยนด้วย `--projects-dir` หรือ `WIFI_SURVEY_HOME`)

## ติดตั้งและรัน
```bash
cd wifi-survey
pip install -r requirements.txt   # ต้องใช้แค่ reportlab (+ Pillow ที่มากับ reportlab)
python run.py                     # เปิดเบราว์เซอร์ที่ http://127.0.0.1:8765
```
ต้องใช้ Python 3.9+ ตัวโปรแกรมไม่มีไลบรารีฝั่งเว็บอื่น ๆ ใช้ออฟไลน์ได้

## การสแกนบนแต่ละระบบ
| ระบบ | ใช้คำสั่ง | หมายเหตุ |
|---|---|---|
| Windows | `netsh wlan show networks mode=bssid` | ให้ค่าเป็น % → แปลงเป็น dBm โดยประมาณ (`%/2 − 100`); ต้องเปิด Location Services |
| Linux | `nmcli` (หรือ `iw dev <if> scan` ถ้ามีสิทธิ์ root) | nmcli ให้ค่าเป็น % เช่นกัน; `iw` ให้ dBm จริง |
| macOS | `airport -s` / `system_profiler` | macOS 14.4+ ไม่มี airport → ใช้ system_profiler (ไม่มี BSSID จริง) ต้องอนุญาต Location |

ข้อควรรู้: ค่าที่ได้เป็นมุมมองของ **การ์ด Wi-Fi ของโน้ตบุ๊ก** ไม่ใช่เครื่องวัดมืออาชีพ ใช้เปรียบเทียบจุดต่อจุดได้ดี
แต่ค่าสัมบูรณ์อาจต่างจากอุปกรณ์ลูกข่ายจริงหลาย dB และการสแกนของ OS บางตัวแคชผลไว้ (แนะนำตั้ง 2–3 รอบ/จุด)
ถ้าเครื่องไม่รองรับการสแกน โปรแกรมจะสลับเป็น **โหมดจำลอง** ให้อัตโนมัติ

## วิธีใช้งานย่อ
1. อัปโหลดแปลน → กด **ตั้งสเกล** คลิก 2 จุดที่รู้ระยะจริง แล้วกรอกเป็นเมตร
2. เลือก **📍 จุดวัด** เดินไปยืนจุดนั้นจริง ๆ แล้วคลิกตำแหน่งบนแปลน รอสแกนเสร็จ
3. ดู heatmap / ปรับเกณฑ์ RSSI (ค่าเริ่มต้น −67 dBm สำหรับเสียง/วิดีโอ)
4. (ทางเลือก) วาง **📡 AP** เพื่อจำลอง แล้วสลับแหล่งข้อมูล heatmap เป็น "จำลอง"
5. กรอกชื่อผู้สำรวจ → **สร้างรายงาน PDF**

รายงานภาษาไทยต้องมีฟอนต์ TrueType ที่รองรับไทยในเครื่อง (Tahoma/Loma/Noto Sans Thai ฯลฯ) หรือวางไฟล์เป็น
`wifi_survey/fonts/Thai.ttf`; ถ้าไม่พบจะใช้ภาษาอังกฤษแทน

## ข้อจำกัดปัจจุบัน
- Heatmap แบบวัดจริงไม่รู้จัก "ผนัง" (ประมาณค่าจากจุดวัดเท่านั้น) และโมเดลจำลองยังไม่คิดการลดทอนจากผนังแต่ละชนิด
- ยังไม่วัดความเร็ว (iperf), ไม่รองรับแปลน PDF โดยตรง (แปลงเป็นรูปก่อน)
